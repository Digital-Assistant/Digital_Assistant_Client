## 2. GitHub Issue Details

**Parent Story Context ([#65] API Service Layer Abstraction):**
This story consolidates all backend interactions into a single, controlled layer within the SDK. By removing data fetching from the UI, we make the UI simpler and more resilient to API changes. It also enhances security by ensuring that all requests pass through a single, authenticated client that properly manages the user's JWT.

**Current Task ([#77] Task: Create a Central API Client):**
*   **Objective:** To create a single, reusable Axios instance that automatically handles authentication for all internal SDK services.
*   **Detailed Information:** Create `packages/core/src/services/apiClient.ts`. Instantiate Axios. Create an interceptor that reads the JWT from the Redux store (`store.getState().user.token`) and attaches it as an `Authorization: Bearer <token>` header to every request. Refactor the migrated services to use this single client instance.
*   **Dependencies:** Task: Migrate Data Services (Granular), [Story] Centralized State Management.
*   **Acceptance Criteria:** All services within the SDK use the central client, and all outgoing requests are automatically authenticated.
